# How to Get Binaural Beats Audio Files

## Quick Option: Online Generator (Easiest)

### 1. Binaural Beats Generator
**Website:** https://www.binauralbeatsmeditation.com/generator/

**For Alpha 10Hz (Calm Focus):**
- Carrier Frequency: 200 Hz
- Beat Frequency: 10 Hz
- Duration: 5-10 minutes
- Export as MP3
- Save as: `alpha_10hz.mp3`

**For Theta 6Hz (Wind-Down):**
- Carrier Frequency: 200 Hz
- Beat Frequency: 6 Hz
- Duration: 5-10 minutes
- Export as MP3
- Save as: `theta_6hz.mp3`

### 2. MyNoise Binaural Generator
**Website:** https://mynoise.net/NoiseMachines/binauralGenerator.php
- Adjust sliders to create desired frequency
- Export as audio file

## Desktop Software (More Control)

### Gnaural (Free, Open Source)
**Download:** https://sourceforge.net/projects/gnaural/

**Steps:**
1. Install and open Gnaural
2. Create new session
3. Set Base Frequency: 200 Hz
4. Set Beat Frequency: 10 Hz (for alpha) or 6 Hz (for theta)
5. Set duration: 5-10 minutes
6. Export as WAV or MP3
7. Convert to MP3 if needed (use online converter or Audacity)

### Audacity (Free)
**Download:** https://www.audacityteam.org/

**Steps for Alpha 10Hz:**
1. Open Audacity
2. Generate → Tone Generator
3. Left Channel: 200 Hz, 5-10 minutes, Amplitude 0.3
4. Generate → Tone Generator (new track)
5. Right Channel: 210 Hz, 5-10 minutes, Amplitude 0.3
6. Select both tracks → Tracks → Mix → Mix and Render
7. Add fade in/out (Select → Effect → Fade In/Out)
8. File → Export → Export as MP3

**Steps for Theta 6Hz:**
- Same as above, but Right Channel: 206 Hz

## Alternative: YouTube to MP3 (If you find suitable tracks)

1. Search YouTube for "binaural beats 10hz" or "binaural beats 6hz"
2. Use a YouTube to MP3 converter (ensure it's legal in your region)
3. Download and rename files appropriately

**Note:** Make sure the tracks are specifically binaural beats (different frequencies in each ear), not monaural beats.

---

## File Requirements

- **Format:** MP3
- **Duration:** 5-10 minutes (will loop seamlessly)
- **Quality:** 128-192 kbps is sufficient
- **Stereo:** Must have different frequencies in left/right channels
- **Fade:** Should fade in/out smoothly for seamless looping

---

## Quick Test

After adding files, test by:
1. Enabling Calm Mode
2. Enabling Binaural Beats
3. Selecting a mode (Wind-Down or Calm Focus)
4. Starting a video
5. Wearing headphones - you should hear the subtle beat

---

## Troubleshooting

**Files not playing?**
- Check file names are exactly: `alpha_10hz.mp3` and `theta_6hz.mp3`
- Ensure files are in `assets/audio/` folder
- Verify files are valid MP3 format
- Check that headphones are connected

**Beats too loud/quiet?**
- Adjust volume in Parental Settings → Binaural Beats → Volume slider
