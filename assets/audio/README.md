# Audio Assets for Binaural Beats

This folder should contain two audio files for binaural beats:

1. **alpha_10hz.mp3** - Alpha waves (10 Hz) for calm focus
   - Left ear: 200 Hz
   - Right ear: 210 Hz
   - Creates a 10 Hz binaural beat

2. **theta_6hz.mp3** - Theta waves (6 Hz) for wind-down/relaxation
   - Left ear: 200 Hz
   - Right ear: 206 Hz
   - Creates a 6 Hz binaural beat

## How to Generate These Files

You can generate binaural beats using:

1. **Online Tools:**
   - https://www.binauralbeatsmeditation.com/generator/
   - Set carrier frequency to 200 Hz
   - Set beat frequency to 10 Hz for alpha or 6 Hz for theta

2. **Desktop Software:**
   - **Gnaural** (free, open-source): http://gnaural.sourceforge.net/
   - **Audacity** (free): Use tone generator with different frequencies for left/right channels

3. **Requirements:**
   - Format: MP3
   - Duration: 5-10 minutes (will loop seamlessly)
   - Should fade in/out smoothly at start/end for seamless looping
   - Stereo (left and right channels must be different frequencies)

## Notes

- Binaural beats only work with stereo headphones
- The beats should be subtle (low volume) to not overpower video audio
- Files should loop seamlessly without clicks or pops
