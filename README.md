# Kids TV Mobile App

A simple Flutter mobile app that allows kids to watch YouTube videos with a kid-friendly interface, including search, categories, playlists, and comprehensive parental controls.

## Features

- YouTube video playback
- Video search functionality
- Categories/genres browsing
- Custom playlists
- Parental controls:
  - Daily time limits
  - Content filtering
  - Password protection

## Setup

1. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```

2. Add your YouTube API key:
   - Get a YouTube Data API v3 key from [Google Cloud Console](https://console.cloud.google.com/)
   - Add it to `lib/utils/constants.dart`

3. Run the app:
   ```bash
   flutter run
   ```

## Requirements

- Flutter SDK 3.0.0 or higher
- YouTube Data API v3 key
- Android SDK or Xcode (for iOS)
